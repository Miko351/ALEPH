# 지역 관광 비교

지역 관광 현황을 살피는 사람이 같은 기간의 방문과 관광소비 규모를 비교하고, 증가율을 따로 확인할 수 있는 과제 13 앱입니다.

1. 서로 다른 지역 두 곳과 기간을 선택합니다.
2. 규모 보기에서 방문과 관광소비를 나란히 비교합니다.
3. 증가율 보기에서 전년의 같은 기간과 비교한 변화를 확인합니다. 전년 자료가 있는 기간에서 사용할 수 있습니다.

화면의 지역명과 지역별 수치는 예시입니다. 기준과 순위상관 수치는 과제 10 논문 「지역별 방문 규모와 관광소비의 관계」에서 가져왔습니다.

## 로컬 실행

1. Python 3으로 프로젝트 폴더에서 `python -m http.server 8000 --directory dist`를 실행합니다.
2. 브라우저에서 `http://localhost:8000/`을 열고 포트폴리오의 대표작에서 **앱 열기**를 누릅니다. 앱을 바로 열려면 `http://localhost:8000/tourism-compare/`로 접속합니다.

Vercel의 정적 파일 출력 폴더는 `dist`입니다.
