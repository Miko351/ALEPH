# BR-A 포트폴리오

- 정적 사이트 소스는 `dist/`에 있습니다. `portfolio` 브랜치의 `dist`를 공개 루트로 지정합니다. 집계 JSON을 읽으므로 확인할 때 HTTP로 엽니다.
- `자료/`에는 갱신 장치, 리추얼 원본, 지원 문서 초안, 제출용 ZIP이 있습니다. 실행법은 `자료/갱신장치_안내.md`에 있습니다. 이 폴더는 Git에서 제외됩니다.

## 공개 전 확정할 내용

- 첫 화면에는 선택한 한 줄 소개를 반영했습니다. 본편 첫 문장과 마지막 문장은 본인이 작성합니다.
- `내 제출 현황`의 총 건수와 기준일을 `자료/입력/projects.json`의 `submissions.count`와 `submissions.asOf`에 입력합니다. 정규 과제 종류 수는 `submissions.regularCount`에 적습니다.
- 과제 13 예정일을 확인해 대표작 카드에 적습니다.
- 지원 문서 초안의 본편을 확정해 문서로 내보냅니다.
